# Foreman server plugin

The Paper plugin: an MCP server inside your Minecraft server, with the dev-server tools (`server_command`,
`server_log`, `server_plugins`…), the world tools, and the tools other plugins publish through `ForemanTools`.

Put the jar in `plugins/` (with FastAsyncWorldEdit for the world tools) and start the server; the log shows the MCP
address (`http://127.0.0.1:25599/mcp` by default).
